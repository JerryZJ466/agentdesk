## 如何看这份名单

- **A：正文核验**——本次可以直接读到官方岗位正文；仍应在投递当天重新检查。
- **B：官方索引核验**——能读到搜索引擎抓取的官方 ATS 正文，但直接访问只返回 JavaScript 页面；不能据此保证申请入口仍有效。
- **人才池**——公司明确说明不是某个确定空缺，不能算成一个已开放的具体团队名额。
- “未说明”表示本次 JD 没有明确工作授权或 sponsorship 政策，不等于接受或拒绝国际学生。申请表询问 sponsorship 也不等于公司承诺提供。

## 对两个项目的实际含义

1. **MeetLoop 不需要变成 Swift + RN + Kotlin + Go 四门等深。** Apple 的能力参照强调原生工程；Circleback 则直接出现 RN、API 与端到端产品交付。保留 Swift / iOS 深度、RN 可发布功能、调试 / 性能 / 测试即可形成清楚的求职叙事；Go 和 Android 按产品实际需要补。
2. **AgentDesk 不应只做框架调用示例。** Sierra / HP IQ 说明 AI 应用实习可以不走论文或训练算法路线；Netic 把 harness、sandbox、eval、失败恢复写进实习工作。因此 Python / TypeScript、服务接口、状态与工具执行、权限、评估与可观测性应继续是核心，模型服务平台专项可后置。
3. **两条路线都需要通用 SDE 基础。** Amazon 的样本明确要求编程、DSA 与 OOP；项目不替代编码面试、调试、测试和讲清设计取舍。每周 CS / 面试训练不要归零。
4. **检索职位名称要比技术栈宽。** iOS / Mobile Software Engineer Intern、Software Engineer Intern 是第一组；React Native 常藏在 JD 内。AI 侧查 Software Engineer Intern + Agent / Applied AI / Product / Full Stack / Backend；不要只搜“Agent Engineer”，也不要把 Research Intern 当成应用工程实习。

## 2027 / 2028 投递时间判断

- 以上多数具体岗位是 **2027 年**，不能称作“2028 已经开始招聘”。根据当前提前发布下一年暑期岗位的现象，**2027 年中开始准备并跟踪 2028 暑期招聘**是合理安排，但这是规划推断，不是所有公司的统一日历。
- 你尚未明确美国学校、入学日和硕士毕业日。应先把这些填入投递表，再筛毕业窗口；例如 Sierra 的 2027 实习毕业限制与 Amazon 不同，不能只看“硕士可投”。
- 若 2027 年秋季才赴美，不能直接假定自己能参加 2027 年夏季美国实习。具体学校、可用工作授权及雇主政策必须分别核实；本表没有替你作资格判断。
- 对你的准备优先级：先把 iOS 核心完成到可演示、可独立修改和可解释的水平，争取近期移动端实习；RN 与 AgentDesk 随后达到可靠交付水平，为读研后下一轮实习扩大投递范围。不要为了这份名单临时把两个项目合并。
