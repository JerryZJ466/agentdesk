## 对当前学习路线的影响

1. **移动实习主目标不变**：先过 MeetLoop M0—M3（Swift、UIKit、网络/生命周期、独立排错）再投 iOS；无需等 Android、RN 和 Agent 全部完成。上海具体名额和学生资格到投递窗口再核实。
2. **AI 工程岗位要看后端栈**：百度样本既有 Go/Python/C++ 平台岗，也有明确 Java/Spring 的开放平台岗；AgentDesk 主线练可迁移的 API、权限、评测、恢复，但不保证适配所有语言岗位。
3. **区分三种“AI 实习”**：Agent 应用/平台工程、算法研究、产品/项目管理。带“AI/Agent”不代表和 AgentDesk 主线相同；不为职位名字随意改学习方向。
4. **2027 春季可执行的筛选清单**：官方岗位ID、日常/转正项目、上海是否实际有团队、在校/毕业资格、可入职日期、至少三个月及每周天数、语言栈、是否要求研究。缺一项就记录待确认，不能从标题推断。

本轮最值得保留的上海工程线索是百度 J106843；这是基于地点和正文的匹配判断，**不是录用可能性排序**。腾讯本部和阿里应用工程仍要进入官方筛选页面复核；未验证部分已清楚列出，没有用社招、算法或项目管理岗位替代。
