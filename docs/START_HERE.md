# AgentDesk 从这里开始

## 第一周

1. 阅读 [准备材料说明](../fixtures/准备材料说明.html)。所有数据均为虚构。
2. 学 Python 的列表、字典、函数、异常和隔离环境，读 `fixtures/tickets.json`。
3. 实现 `get_ticket(actor, ticket_id)`：身份来自可信测试上下文，资源租户必须匹配。
4. 写正常、缺失、无权三种情况的断言；区分未找到与内部权限原因的对外返回策略。
5. 关闭 AI 对话，独立增加一个可见性规则，并解释数据流。

## 后三周

- 第 2 周：类型、pytest、HTTP / JSON，FastAPI 两个只读接口和参数校验。
- 第 3 周：SQLite、基础 SQL、日志与确定性调查流程；认识 token 和工具调用。
- 第 4 周：工具 schema、10-20 个场景规格、运行事件与一次需求变更。

第 5 周起再做模型循环。现在不需要 GPU、付费 API、七套框架或多个 Agent。

## 当前材料的边界

`policy.example.json` 是设计示例，`eval_cases.seed.jsonl` 是 12 个开发集规格；权限执行器、故障注入器和评分器尚未实现，不能宣称用例已经通过。
