# AgentDesk 从这里开始

当前主计划：v2.1（2026-10-29）。只按 [当前主计划](plans/plan.md) 的A0-A7推进。先做Python、只读数据与确定性流程，达到A1关卡后才进入模型循环；没有“第5周必须上模型”的要求。

## 第一次约2小时

1. **20分钟**：读 [准备材料说明](../fixtures/准备材料说明.html)，说明输入、输出、用户角色和不能做什么。所有资料是虚构数据；文档内指令不是授权。
2. **30分钟**：确认Python环境，用列表/字典读tickets.json；不会就先看Python对应章节，别复制整段应用。
3. **45分钟**：写get_ticket(actor, ticket_id)，actor由可信测试上下文提供；u-n-viewer可读T-1001，不可读T-2001。
4. **25分钟**：给正常、缺失、无权写断言；关掉AI对话改一个条件，解释数据流。记录失败也算有效学习，不自动标通过。

## 第一周5小时

环境与基线1h、Python练习1.5h、查询实现1.5h、断言与复盘1h。A0共10-15h，可占2-3周；语言基础弱就延长。

## 前四周约20小时

| 周 | 重点 | 证据 |
| --- | --- | --- |
| 1 | Python环境、读JSON、受限查询 | 一份能解释的小程序 |
| 2 | 函数、异常、断言/pytest、独立变式 | 正常/缺失/无权测试 |
| 3 | A0过关；一页需求与规则调查流程 | 角色、输入输出、成功标准与非目标 |
| 4 | 开始A1，按基础选HTTP接口或SQL | 一个可验证的小任务；不要求API、SQL、Agent同时完工 |

A0+A1共60-85h；按5h/周约12-17周。若已有Python/SQL能力，可独立通过任务后跳过相应补课；不能因为自己用AI做过类似代码就直接认定掌握。

## 开工核对

- [ ] Git远程为自己的agentdesk；当前数据均为虚构。
- [ ] Python与隔离环境可用；依赖与命令可记录复现。
- [ ] 用可信测试身份完成查询，知道它不是正式登录方案。
- [ ] 12条eval是规格；尚无runner、评分、权限引擎或沙箱通过结果。
- [ ] 第一阶段不需要GPU、付费API、Docker集群或多Agent框架。

真实模型接入在A2；代码执行在A6的隔离验收之后。每个阶段具体材料扩充见 [准备审核](PREPARATION_AUDIT.md)。资料：[Python教程](https://docs.python.org/3/tutorial/) · [pytest](https://docs.pytest.org/en/stable/getting-started.html) · [进度账本](PROGRESS.md)

主次确认：iOS/RN与Agent/AI应用是核心；Android/Go/FDE/平台为附加。最新累计估时见[实习时间](面试准备与时间评估.md)。
