## 需要守住的学习边界

**后端与 Web 基础必须亲手做。** 开发阶段的 fixture actor 不是上线身份认证；增加真实 HTTP 边界时要练连接复用、分页、schema 变化、429/超时及安全重试。控制台要能解释浏览器状态、请求与授权，而非仅把组件拼起来。每阶段安排一次 60–90 分钟独立改题或排障，每周保留数据结构、网络、OS、SQL 与项目讲解训练。会使用 AI 编码工具是能力，能验证生成结果才构成工程证据。

**基础能力先于框架数量。** 一个教学循环加一个主 SDK 足够形成主线。其他开源项目按机制选读；MCP 先做一个只读工具实验；多 Agent、长期记忆、复杂微服务和 Kubernetes 均不默认成为首版依赖。固定脚本足以分析 CSV 时，先用固定脚本；需要生成代码时才引入完整隔离执行。

**时间以当前主计划统一口径执行。** 不再把旧稿“44周”解释成每周7小时即可完成400小时。阶段工时是估算，只有通过产物、解释、改题和故障验收才过关。模型服务平台另计 **100–160 小时选修**，围绕已有 ServeLab 补 Linux、网络、队列背压、容量和 vLLM 测量，避免在 AgentDesk 重建同等网关。它也不等于 GPU 内核、分布式训练或算法研究能力。

这些样本支持以 AI 应用/Agent 实习或初级 SDE 为切入口、再根据目标岗位增加 FDE 或平台深度。它们不能保证一两年后的岗位数量与录用结果；可以持续复用的能力是独立编码、调试、数据处理、验证、系统边界和交付。
