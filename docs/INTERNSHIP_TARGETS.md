# 实习目标清单：iOS / RN 与 Agent / AI 应用

核对日期：2026-10-29。核心能力达到实习关卡后可以向下面的岗位类型投递，但当前样本不保证2027/2028仍开放，更不代表已满足每个岗位的资格。两个项目独立，不要求先学完Android、Go、FDE或模型平台。

证据：**正文**＝本次直接读取官方JD；**索引**＝官方地址的搜索正文可读、直开动态页面未成功；**标题/入口**＝只可确认标题或招聘入口；**线索**＝第三方信息，官方详情尚未核实。所有未说明的毕业窗口/时长/工作授权都保留待确认。

## 先选对岗位类型

| 主线 | 主投关键词 | 不应仅凭名字误投 |
| --- | --- | --- |
| MeetLoop | iOS开发实习、移动客户端实习、跨端开发、Mobile Software Engineer Intern；在JD中查React Native | Unity/UE游戏客户端；只做浏览器Web而要求完整CSS/DOM深度的岗位 |
| AgentDesk | AI应用研发、Agent开发、智能体工程、AI全栈、后端开发（LLM/工具/工作流）、Software Engineer Intern–Agent/Applied AI | 需要论文/训练/RL的算法研究；以标注、人工评测、产品运营为主的岗位 |
| 两项目共同支撑 | 产品型SDE/全栈实习；仍需语言栈和编码基础匹配 | 不默认满足Java/Spring、底层GPU、分布式训练等未学专项 |

RN经常在JD职责中出现，职位名称可能只有“客户端”或“Software Engineer”。先用iOS强项申请，RN作为第二项能力；不要只搜含“RN”的岗位名。

## 时间、资格与申请顺序

- 若2027秋才赴美，主规划更适合围绕读研后的实习窗口；不要把现在的2027暑期样本当成2028已开放名额。2027年中开始准备/查看2028暑期是个人安排推断，不是所有公司的统一时间表。
- 国内准备简历时写清实际毕业时间、计划读研、能到岗日期和持续时长；是否符合学生实习身份按具体公司确认。小红书≥4个月与原先3个月窗口的冲突必须提前处理。
- 美国在读/毕业窗口、返校要求和工作授权分别核对。未注明sponsorship不等于接受或拒绝国际学生；不能仅因“去美国读研”就认定可投全部岗位。
- 两份定向简历：移动版突出字节实习+MeetLoop，AI版突出AgentDesk+能解释的既有项目；不要把选修、未完成模块或参考服务写成自己的生产成果。
- 项目通过后仍需编码面试、CS基础和表达。岗位不匹配时优先换同类JD，不能为每家公司临时再学一套语言/训练算法。
