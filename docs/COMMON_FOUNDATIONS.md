# 公共基础与面试训练

两个项目共享知识，但仓库、业务与部署独立。同一小时只记一次。公共基础每周3h已经包含在21h总预算里。

| 每周安排 | 做什么 | 留下什么 |
| --- | --- | --- |
| 90分钟编码/DSA | 理解一种结构、独立做一道变式、隔周重做；固定一种面试语言 | 正确性、复杂度、边界测试和卡点 |
| 60分钟系统基础 | HTTP/TLS/DNS、OS与并发、SQL轮换，结合项目实验 | 一页解释与可复现命令或测试 |
| 30分钟表达 | 项目讲解、实习复盘、中文或英文演示 | 3分钟录屏或简短讲稿 |

## 前四周示例

| 周 | 编码主题 | 系统主题 | 表达 |
| --- | --- | --- | --- |
| 1 | 数组、哈希、去重、时间复杂度 | Git diff/commit/branch；HTTP请求/响应 | 解释MeetLoop报名规则 |
| 2 | 字符串、双指针、边界条件 | HTTP状态、幂等、超时与重试 | 解释工单权限 |
| 3 | 栈/队列、二分 | SQL唯一约束、事务、索引与EXPLAIN小实验 | 一次测试失败怎样定位 |
| 4 | 树遍历或复习最弱主题 | 进程/线程/异步任务、取消与共享状态 | 45分钟独立变更复测 |

之后依次补树/图、堆、排序与基础动态规划；面试目标决定深度，不追题量。准备集中笔试时可以把公共基础提高到4-5h，但从项目时间中挪出，不能增加隐形预算。

## 学习资料

- [Pro Git](https://git-scm.com/book/en/v2)：基础、分支、差异与回滚；用自己仓库做小实验。
- [MIT Missing Semester](https://missing.csail.mit.edu/)：终端、调试与开发工具；按需选学。
- [MIT 6.006](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)：数据结构和复杂度；课程强度较高，作为对应主题参考，不整套并行。
- [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html)：SQL基础；在虚构数据上试事务与索引。
- [MDN Web核心](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core)：浏览器基础主要在AgentDesk A4计时，避免重复。

## 使用AI的训练约定

先自己写需求、状态/数据流和验证点，再让AI提示或审查。接收代码前读差异、运行相关验证，并用新条件复做。每阶段留一个不靠整段生成的变更证据；不能把自己解释不清的部分写成独立完成。
